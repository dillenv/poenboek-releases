# Poenboek — downloads

Poenboek is een huishoudboekje dat helemaal op je eigen computer draait. Je
zet je Rabobank-export erin, deelt je uitgaven in en ziet waar je geld heen
gaat. Je transacties gaan nooit naar internet.

Deze repository bevat alleen de downloads, onder
[Releases](https://github.com/dillenv/poenboek-releases/releases). De code
staat hier niet.

## Installeren

- **Mac:** download `Poenboek-<versie>.dmg`, open hem en sleep Poenboek naar
  Apps.
- **Windows:** download `Poenboek-<versie>-windows.zip`, pak hem uit en
  dubbelklik `Poenboek.bat`.

## Bijwerken

Heb je Poenboek al (vanaf versie 0.2.0)? Dan meldt de app zelf dat er een
nieuwe versie is, met een knop om bij te werken. Elke versie is digitaal
ondertekend; de app installeert niets wat die handtekening niet heeft.

`latest.json` in elke release is wat de app ophaalt om te zien of er iets
nieuws is. Er gaat daarbij niets van jou mee.
